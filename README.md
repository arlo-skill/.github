# Arlo Skill · 组织主页

本仓库维护 [Arlo Skill](https://github.com/arlo-skill) 的组织介绍与技能目录。

组织首页展示的内容位于 **[profile/README.md](profile/README.md)**，包括组织定位、已发布技能、一行安装方法及反馈入口。

## 维护方式

- 修改组织介绍或更新技能目录时，编辑 `profile/README.md`。
- 新技能在独立仓库中维护，并在目录中添加真实可访问的仓库链接与用途说明。
- 每个技能的详细规范、配置模板和安装说明保留在对应仓库，组织主页提供概览与入口。

GitHub 的展示规则见[组织主页自定义文档](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)。
